# karkain-tmLanguage

TextMate grammar for the [Karkain](https://github.com/ajit-ai/Karkain)
programming language, intended for editor and tooling reuse (including a
future GitHub Linguist contribution).

- Karkain source files use the `.kark` extension.
- Grammar scope is `source.karkain`.
- Layout follows the TextMate grammar convention consumed by Linguist's
  `script/add-grammar`: `grammars/karkain.tmLanguage.json`.

## Status

No claims are made about GitHub Linguist acceptance, GitHub language-bar
support, official GitHub recognition, or upstream Linguist approval. Those
are future outcomes pursued in the canonical Karkain repository.
